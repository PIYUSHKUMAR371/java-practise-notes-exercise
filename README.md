# ☕ Java Learning Repository — From Zero to Hero

A friendly, structured, beginner-to-advanced Java learning repo 
covering 71 topics across 9 modules. This is based on BroCode's Java 
Full Course. Every topic has notes and exercises.

## 🗺️ How to Use This Repo

1. **Start with HOW_TO_START.md** - If you're a total beginner, this file will guide you through installing Java and an IDE.

2. **Follow the Modules in Order** - Start from Module_01 and work your way up. Don't skip ahead!

3. **Read the Notes First** - For each topic, open the Notes_[TopicName].java file. It explains the concept with simple analogies and runnable examples.

4. **Do the Exercises** - After reading the notes, complete the Exercise_[TopicName].java file. It has 3 exercises with hints.

5. **Build the Projects** - Projects are marked with ⭐ in the topic list. They combine multiple concepts into fun, runnable programs.

6. **Track Your Progress** - Use the checklist below to mark off completed topics.

## 🚀 Getting Started

### Install Java
- Download the latest JDK from [oracle.com](https://www.oracle.com/java/technologies/javase-downloads.html)
- Follow the installation instructions for your OS

### Install an IDE
- **VS Code** (Recommended for beginners): Install from [code.visualstudio.com](https://code.visualstudio.com/), then add the Java Extension Pack
- **IntelliJ IDEA** (More advanced): Community edition is free from [jetbrains.com](https://www.jetbrains.com/idea/)

### How to Run Java Files
1. Open the .java file in your IDE
2. Click the "Run" button (usually a play icon)
3. Or use terminal: `javac FileName.java` then `java FileName`

## 💡 Tips for Beginners

1. **Don't rush** - Take your time with each concept. Understanding > Speed
2. **Experiment** - Change values in the code and see what happens
3. **Google everything** - If something doesn't make sense, search for it
4. **Practice daily** - Even 30 minutes a day is better than cramming
5. **Join communities** - Reddit's r/learnjava or Discord servers for help
6. **Build projects** - Apply what you learn in small projects
7. **Don't fear errors** - Errors are learning opportunities
